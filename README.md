# Mila YAELNET — Recovered Baseline and Adaptive Vocabulary P0

P0 provides typed Hebrew-to-Arabic and Arabic-to-Hebrew active recall, independent progress by direction, delayed retry after errors, bounded retries, priority adjustment, resumable sessions, and isolated namespace mila-yaelnet-adaptive-v1. Original vocabulary IDs and entries are reused. Existing progress namespaces and the legacy scheduler remain untouched. Long-term FSRS and advanced formats are deferred.

This is a recovered deployment baseline, not a verified original repository checkout. The deployed Flask app.py was listed by Vercel but its source response was truncated. No replacement server entry point was guessed. Preview and production deployment are blocked until the exact app.py is restored.

Runtime archive is stored in ordered payload/part-* files. It is a 146026-byte gzip tar archive split into 105 chunks. Tests: npm --prefix tests install && npm --prefix tests test.
